# [Thực hành] Xây dựng Trang Chủ với Bootstrap

Bài thực hành tạo trang chủ linh hoạt kết hợp các tính năng nổi bật của Bootstrap 5 theo chuẩn CodeGym.

## Nội dung thực hiện
1. **Cài đặt thư viện**: Nhúng Bootstrap 5.3.3 (CSS & JS) và Font Awesome 6.5.2 CDN.
2. **Navbar**: Thanh điều hướng có gắn icon Font Awesome (`fas fa-home`) và menu tự động căn phải (`ms-auto`).
3. **Hero Section với Carousel**: Tạo slideshow chuyển ảnh tự động (`#heroCarousel`) với nút chuyển tiếp Prev/Next.
4. **Flexbox Section**: Căn giữa tiêu đề trang web trên nền sáng sử dụng `d-flex justify-content-center align-items-center`.
5. **Contact Form**: Form liên hệ chuẩn Bootstrap với các trường nhập tên, email và nút gửi.

## Công nghệ sử dụng
- HTML5
- Bootstrap 5.3.3
- Font Awesome 6.5.2
